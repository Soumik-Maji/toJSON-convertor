# toJSON-convertor
Basic conversion of csv, xml, xlsx data to json format.

**NOTE:** Project is ready to use, with ongoing maintenance and updates to follow. Minor API changes may occur.

Currently support conversion of csv, xml & xlsx data to flat json(array of objects) format.

Future addition - Conversion from html & yaml.

Refer to the [GitHub repo test directory](https://github.com/Soumik-Maji/toJSON-convertor/tree/release/tests/test-scripts), for usage examples.
